# 写实图书馆静态样片

> 历史实施记录（2026-10-03 收尾标记）：下文保留当时的方案和验证，不是当前待办。现役功能、素材和启动方法以 [README](../../../README.md) 为准。

用户批准先制作实际网页渲染的静态样片，验收人物、材质与布光。当前互动页不变。

## 实施

1. 获取可使用的宇航服模型与 PBR 木纹材质，记录原始来源与许可；检查实际模型质量，静态样片不要求动画骨骼。
2. 新建 `library-study.html`、`css/library-study.css`、`js/library-study.js`，使用独立场景，构建带倒角的深色木书架、金属支撑和有厚度的书本。
3. 所有人物和书架在同一场景中渲染，使用斜向主光、冷色环境光、局部光束及阴影。固定第三人称斜漂姿态与相机，不添加动画或交互功能。
4. 浏览器加载真实本地资产，输出全景与人物细节截图，检查错误、资源完整性和不同屏幕适配。交付独立预览链接与截图。

## 验收

- 画面包含可辨认的写实宇航服、木纹、金属及书籍厚度。
- 人物与环境共享光源和遮挡，保持冷暗底色及局部日光。
- 样片不依赖外部实时资源，不改变现有图书馆。
- 明确记录模型与动画绑定的实际状态，不将静态样片称为完整升级。

## 本轮交付与验证

- 独立入口：`library-study.html`。现有互动场景和音乐代码未修改。
- 候选模型：NASA Z2 Spacesuit；运行时调整静态姿态与法线，没有动画骨骼。
- 材质：Poly Haven Dark Wood 色彩、法线及粗糙度贴图；书架倒角、金属包边、书本厚度。
- 布光：局部象牙白窗光、冷色环境补光、投射阴影、柔和光束及少量静态尘粒；远景轻度虚化。
- Edge 浏览器实际加载通过：1920×1080 桌面、390×844 手机视口模拟。无页面错误、无 HTTP 失败资源，静止后不持续渲染。
- 实际截图：`artifacts/library-study/desktop.png`、`detail.png`、`mobile.png`；检查数据：`checks.json`。
- `node --test tests/project-structure.cjs` 的 3 项检查通过；`git diff --check` 通过。
- 本轮未上线。样片仅为材质、人物及光照验收，不代表最终动态画面质量、动画绑定或性能已经验收。
