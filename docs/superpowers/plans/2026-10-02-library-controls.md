# 图书馆简洁控件调整

> 历史实施记录（2026-10-03 收尾标记）：下文保留当时的方案和验证，不是当前待办。现役功能、素材和启动方法以 [README](../../../README.md) 为准。

用户已批准：移除标题介绍、暂停按钮、状态与藏书计数、速度指示和原大按钮。底部只放「长按 · 加速」，按住显示「松开 · 减速」；右上角只放小音符，中文提示，亮暗区分播放状态。保留返回主页、顶部标识、素材致谢和已有场景效果。

1. 调整 `library.html` 与 `css/library.css`：删去指定元素及孤立样式，底部按钮居中，音乐按钮保留至少 44px 的触摸区域。
2. 调整 `js/library.js`：清理删除元素的引用，按钮文案随按下/释放变化，减少动态效果模式下提供同一个按钮作为开始入口，支持键盘与触摸。
3. 调整 `js/library-music.js`：音乐状态改为图标亮暗和中文 title/aria-label，保留播放逻辑。
4. 更新依赖旧暂停按钮的浏览器测试，使用系统减少动态效果模拟暂停。运行控件、原交互与音乐测试，并检查桌面、手机截图。

## 验证结果

- 红框内元素及其脚本引用、孤立样式已移除。底部按钮宽 140px、高至少 44px；音乐按钮 44px，仅显示音符，title 与 aria-label 均为中文。
- `library-controls.cjs` 先在旧界面因仍有 4 类待移除元素失败，修改后桌面与手机均通过。覆盖长按文案、加速/释放、减少动态效果暂停与开始入口，以及音乐图标的键盘操作。
- 同时修复空格释放事件拦截音乐按钮原生点击的问题；新检查先超时失败，限制 preventDefault 的作用范围后通过。
- `library-audio.cjs` 在允许自动播放、要求用户交互两种浏览器策略下，桌面及手机模拟的实播、暂停、续播与循环全部通过。
- `library-browser.cjs`、`library-scatter.cjs`、`library-horizon.cjs`、`library-light.cjs` 通过；运动与项目结构 7 项测试通过，`git diff --check` 通过。
- 已检查桌面、手机截图，位于 `artifacts/library/controls-desktop.png` 和 `controls-mobile.png`。
