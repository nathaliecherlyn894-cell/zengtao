# PPT 作品墙修复计划

**目标：** 保留两端拖动时缩小至 75% 和四周滚动的 DRAG 边框；手机默认一列半，修复循环缺口与完整预览。

**实现范围：** 只修改 `index.html` 中 PPT 页面样式、作品墙及大图交互。沿用原生 HTML/CSS/JavaScript，不引入运行时依赖。使用 `tests/ppt-wall.cjs` 做浏览器回归检查。

**方案：** 为作品墙建立可测量的展示窗口。根据最小缩放 0.75 时的可视范围，加上屏幕外缓冲，计算循环网格行列数；复用 16 张素材填满网格。循环边界放在可视范围之外。手机展示窗口内卡片宽度为 `(窗口宽度 - 横向间距) / 1.5`，静止时一整列和半列，交互缩小时自然显示更多作品。

- [ ] 先写回归检查：采样多个拖动位置及缩放比例，检查任意列间空隙不超过正常间距；手机卡片符合一列半；大图可见且不超出屏幕。运行原版，确认失败原因。
- [ ] 修复排列：以展示窗口实际宽高计算尺寸；按最小缩放补齐网格及屏幕外缓冲；只在缓冲外循环；ResizeObserver 响应窗口变化。
- [ ] 修复手机交互：保留四边跑马灯，减小手机边框并预留返回按钮空间；统一 Pointer Events，处理取消、多指及拖动后的点击抑制；手机松手横向对齐卡片。
- [ ] 修复大图：独立固定遮罩、等比例完整显示、关闭按钮、背景关闭及 Escape；点击任意循环副本打开对应素材。
- [ ] 运行浏览器验证：桌面、窄屏手机、常规手机及横屏；连续双向拖动、滚轮、缩放过渡、触摸取消、全部 16 张预览、关闭后再次进入；查看截图并核对 git diff。

**交付边界：** 本地修改和验证，不在本轮推送 GitHub 或发布线上网站。
