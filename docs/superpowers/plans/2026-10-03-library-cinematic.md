# 写实样片接入互动图书馆

> 历史实施记录（2026-10-03 收尾标记）：下文保留当时的方案和验证，不是当前待办。现役功能、素材和启动方法以 [README](../../../README.md) 为准。 写实素材已接入互动页。

用户已验收静态样片并批准继续。将同一模型、材质和布光方向接入现有互动页，保留五边形循环、右下消失点、长按加速与散射、简洁控件和音乐。

1. 载入 NASA Z2 宇航服及本地 PBR 材质；角色沿用样片摆姿，以整体姿态轻微漂浮，不宣称已完成骨骼绑定。验证：本地素材加载、模型细节与朝向截图。
2. 内层木书架增加倒角与材质，保留实例化以限制绘制开销；补充书本背板/书脊厚度。验证：近景截图、循环边界及资源检查。
3. 人物与环境共享渲染深度和窗口阴影，接入冷暗环境反射与局部窗光、克制的高光柔化；运动模糊主要作用于远景。验证：动态窗光一致性、人物遮挡、静止/长按截图。
4. 检查桌面与手机模拟、长按和减速、减少动态效果、音乐及长时循环；测量实际帧间隔并记录运行环境。保留独立样片，不推送或上线。
